## Detaylı Bulgular

### AUD-001 — Orta | `admin_url()` çıktısı `esc_url()` ile sarmalanmamış
- **Dosya:** `gnn-terms-popup.php`
- **Satır:** 84
- **Kod:**
  ```php
  $settings_link = '<a href="' . admin_url('admin.php?page=gnn-terms-popup') . '">' ...
  ```
- **Risk:** `admin_url()` genel olarak güvenlidir ancak WordPress kodlama standartları URL çıktılarında her zaman `esc_url()` kullanılmasını zorunlu kılar.
- **Düzeltme:** `esc_url(admin_url(...))` olarak güncelle.

---

### AUD-002 — Orta | `sanitize_hex_color()` null döndürebilir
- **Dosya:** `gnn-terms-popup.php`
- **Satır:** 177–178
- **Kod:**
  ```php
  $out['primary_color'] = isset($input['primary_color']) ? sanitize_hex_color($input['primary_color']) : $d['primary_color'];
  ```
- **Risk:** Geçersiz hex değer girildiğinde `sanitize_hex_color()` `null` döndürür. null veritabanına kaydedilir ve sonraki render'da CSS değişkenine `null` basılır: `--gnn-primary: ;` → Stil çöker.
- **Düzeltme:** `sanitize_hex_color(...) ?? $d['primary_color']` null coalescing ile fallback ekle.

---

### AUD-003 — Orta | `apply_filters('the_content')` çıktısı sarmalanmıyor
- **Dosya:** `gnn-terms-popup.php`
- **Satır:** 402–404
- **Kod:**
  ```php
  $html = apply_filters('the_content', $page->post_content);
  if (trim(wp_strip_all_tags($html)) !== '') {
      return $html;
  }
  ```
- **Risk:** `the_content` filtresi diğer eklentiler veya içerik editörü tarafından değiştirilebilir. XSS payload içeren bir sayfa içeriği modal'a ham olarak basılabilir.
- **Düzeltme:** `wp_kses_post(apply_filters('the_content', $page->post_content))` olarak güncelle.

---

### AUD-004 — Orta | `after_install()` içinde `$wp_filesystem` null kontrolü yok
- **Dosya:** `inc/updater.php`
- **Satır:** 195–203
- **Kod:**
  ```php
  global $wp_filesystem;
  if ($result['destination'] !== $plugin_dir) {
      $wp_filesystem->move($result['destination'], $plugin_dir);
  ```
- **Risk:** `$wp_filesystem` null olursa `->move()` çağrısı fatal PHP hatası üretir. WordPress `WP_Filesystem()` init fonksiyonu çağrılmadan `$wp_filesystem` null kalabilir.
- **Düzeltme:** `WP_Filesystem()` çağrısı + null guard ekle.

---

### AUD-005 — Orta | Boş API yanıtında sentinel cache yazılmıyor
- **Dosya:** `inc/updater.php`
- **Satır:** 96–98
- **Kod:**
  ```php
  if (empty($body) || !isset($body->tag_name)) {
      return false;
  }
  ```
- **Risk:** API geçersiz yanıt (ama HTTP 200) döndürürse sentinel transient yazılmıyor. Her page load'da yeniden GitHub API'ye request gidebilir. Rate limit aşılabilir veya gereksiz yük oluşur.
- **Düzeltme:** Bu dalda da sentinel `(object)['_failed' => true]` yazarak 5 dakika cache'le.

---
